Operatörler:
sensör verisinden karara

Bir önceki derste sensörün gönderdiği değerleri ve tiplerini gördük. Operatörler, o ham sayıları karara dönüştürür: "31.2 °C mi? O zaman fanı aç." "Pil %18 mi? Geri dön." Bir IoT cihazını "akıllı" yapan şey tam olarak budur.

◇ Operatör = cihazın refleksi

Sensör ölçer, operatör karar verir, aktüatör tepki verir. >, and, + gibi semboller bu zincirin ortasındaki beyindir. Karşılaştırma ve mantık operatörleri sana hep bir bool (True/False) döndürür — yani geçen dersle doğrudan bağlanır.

Örnek 1 — Sıcaklık eşik kontrolü

karşılaştırma + mantıksal operatörler

Bir sera/depo sensörü. Tek eşik yetmez: hem fazla sıcaklığı hem de sıcak+nemli "boğucu" durumu ayrı yönetiriz.

python · esik_kontrol.py
sicaklik = 32.4      # °C  (sensörden float)
nem      = 75        # %   (sensörden int)

if sicaklik > 35:
    print("KRİTİK: aşırı sıcak, sistemi durdur")
elif sicaklik > 30 and nem > 70:
    print("UYARI: sıcak + nemli, havalandır")   # ← bu çalışır
elif sicaklik > 30:
    print("Fanı çalıştır")
else:
    print("Normal aralık")
Mantık
Sıra önemli: en kritik koşul en üstte. elif zinciri ilk doğru olanda durur — bu yüzden 32.4°C + %75'te "aşırı sıcak"a takılmaz, ikinci kurala düşer.

Örnek 2 — Batarya seviyesi karşılaştırma

karşılaştırma + mantıksal + aritmetik

Drone bataryası: ham voltajı yüzdeye çevir, sonra kademeli karar ver. LiPo'da 4.2 V dolu, 3.3 V boş kabul edelim.

python · batarya.py
voltaj = 3.55     # tek hücre LiPo voltajı (float)

# aritmetik: voltajı %'ye çevir (3.3=boş, 4.2=dolu)
yuzde = (voltaj - 3.3) / (4.2 - 3.3) * 100   # ≈ 27.8

if yuzde <= 10:
    print("ACİL: hemen iniş")
elif yuzde <= 25:
    print("DÜŞÜK: eve dönüş başlat")        # ← bu çalışır
elif yuzde < 50:
    print("Görevi kısalt")
else:
    print("Sağlıklı — göreve devam")
Gerçeklik
LiPo voltaj-yüzde ilişkisi aslında doğrusal değildir (deşarj eğrisi). Bu basit formül Faz1 için yeterli; sahada gerçek bir deşarj tablosu (lookup) veya kalman filtresi kullanılır — o, Faz2'nin işi.

Örnek 3 — GPS uzaklık hesabı

aritmetik operatörlerin vitrini (** * / + −)

İki GPS noktası arasındaki gerçek mesafe (Haversine formülü). "Eve dönüş ne kadar uzakta?" ya da "tarla sınırını aştım mı?" sorularının cevabı. Operatörler burada yoğun çalışır.

python · gps_mesafe.py
import math

def gps_mesafe(lat1, lon1, lat2, lon2):
    R = 6371000                  # Dünya yarıçapı (metre)
    dlat = math.radians(lat2 - lat1)
    dlon = math.radians(lon2 - lon1)
    # ** (üs) ve * / + burada iş başında:
    a = math.sin(dlat/2)**2 + \
        math.cos(math.radians(lat1)) * math.cos(math.radians(lat2)) * \
        math.sin(dlon/2)**2
    return R * 2 * math.asin(math.sqrt(a))

# Tokyo İstasyonu → Shibuya
m = gps_mesafe(35.6812, 139.7671, 35.6580, 139.7016)
print(round(m, 1))      # 6454.8 metre

# karar: tarla sınırı 5 km ise aştık mı?
if m > 5000:
    print("Sınır aşıldı — geri çağır")
Bağ
Çok kısa mesafelerde (birkaç yüz metre, tek tarla içi) daha basit bir düzlem yaklaşımı da yeterlidir: mesafe = ((dx)**2 + (dy)**2) ** 0.5 — Pisagor. **0.5 karekök demektir. Haversine ise Dünya'nın eğriliğini hesaba katar, uzun rotalarda doğrudur.
