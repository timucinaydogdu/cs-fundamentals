if / elif / else:
otopilotun karar ağacı

Bir drone saniyede onlarca kez şu soruyu sorar: "Şu an ne yapmalıyım?" Batarya, GPS, rüzgâr verisine bakar ve bir uçuş moduna karar verir. Bu karar ağacının Python'daki karşılığı tam olarak if / elif / else'tir.

◇ Failsafe = sıralı kontrol

Otopilotun failsafe (güvenlik) mantığında sıra her şeydir: en tehlikeli durumu en önce kontrol edersin. if/elif/else tam böyle çalışır — koşulları yukarıdan aşağı dener, ilk doğru olanı çalıştırır ve geri kalanına hiç bakmaz.

Yani "fırtına var mı?" sorusunu "batarya düşük mü?"den önce sorarsan, fırtınada doğru tepkiyi (LAND) garanti edersin. Bu derste hem yapıyı hem de bu sıralama mantığını kuracağız.

⌥

Yapı: üç dal

if bir koşulu test eder; doğruysa altındaki girintili bloğu çalıştırır. elif ("else if") önceki yanlışsa yeni bir koşul dener. else hiçbiri tutmazsa devreye girer — varsayılan davranış.

python · iskelet
if kosul_1:
    # kosul_1 doğruysa SADECE bu çalışır
    yap("A")
elif kosul_2:
    # 1 yanlış AMA 2 doğruysa bu çalışır
    yap("B")
else:
    # hiçbiri tutmazsa bu çalışır
    yap("C")
Girinti
Python'da bloğu girinti (boşluk) tanımlar — süslü parantez yok. Standart 4 boşluk. Girintiyi karıştırırsan IndentationError alırsın. VS Code'da Tab tuşu otomatik 4 boşluk yapar.

⎇

Drone karar ağacı

Failsafe mantığımız, yukarıdan aşağı denenen bir merdiven. İlk tutan koşul kazanır — bu yüzden en kritik tehlike en üstte:

ifrüzgâr ≥ 60 km/h  — fırtınaLAND
elifbatarya ≤ 20 %  — düşük güçRTL
elifGPS yok  — konum kilidi kayıpLOITER
elseher şey normalAUTO
Sıra
Neden fırtına en üstte? Çünkü düşük bataryalı bir dronun fırtınada doğru tepkisi yine de inmektir, eve dönmeye çalışmak değil. En acil/fiziksel tehlike önce gelir. Sıralama, mühendislik kararıdır — kod sadece onu uygular.
▮

Çalışan kod

if / elif / else + karşılaştırma + mantıksal operatörler

python · ucus_modu.py
# --- anlık telemetri (sensörlerden) ---
ruzgar   = 22       # km/h
batarya  = 18       # %
gps_lock = True     # GPS konum kilidi var mı?

# --- karar mantığı: ilk tutan kazanır ---
if ruzgar >= 60:
    mod = "LAND"            # fırtına: olduğun yerde in
elif batarya <= 20:
    mod = "RTL"             # düşük güç: eve dön ← bu çalışır
elif not gps_lock:
    mod = "LOITER"          # GPS yok: konumda bekle
else:
    mod = "AUTO"            # normal: göreve devam

print("Uçuş modu:", mod)   # Uçuş modu: RTL
Mühendislik notu
Gerçek ArduPilot/PX4'te küçük ama önemli bir incelik var: LOITER konum tutmak için GPS'e ihtiyaç duyar. Yani GPS tamamen kaybolursa otopilot LOITER'a değil, GPS gerektirmeyen ALT_HOLD (sadece irtifa tut) ya da STABILIZE moduna düşer. Senaryoda LOITER'ı yapıyı öğrenmek için kullandık; sahada bu ayrımı bilmek sınav/iş görüşmesinde fark yaratır.
!

Üç sık hata

python · kaçın
# 1) = yerine == (atama / karşılaştırma karışıklığı)
if batarya = 20:      # ✕ SyntaxError
if batarya == 20:     # ✓ doğru

# 2) yanlış sıra — kritik koşul alttaysa hiç çalışmaz
if batarya < 50:     # bu önce tutar, alttaki
    mod = "RTL"
elif batarya < 15:   # ← buraya ASLA ulaşılmaz!
    mod = "LAND"

# 3) else unutmak — beklenmedik durumda mod tanımsız kalır
Kural
