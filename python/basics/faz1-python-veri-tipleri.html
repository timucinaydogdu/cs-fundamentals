Veri tipleri:
int · float · str · bool

Her sensör sana bir değer gönderir — ama bu değerin tipi, onunla ne yapabileceğini belirler. Sıcaklığı toplayabilir, sensör ID'sini metinle birleştirebilir, "hareket var mı?" sorusuna evet/hayır cevabı verebilirsin. Dört temel tipi gerçek IoT verisiyle görelim.

◇ IoT'de tip neden hayati?

Bir sensör 23.5 gönderdiğinde Python bunu nasıl saklasın? Tam sayı mı (int), ondalıklı mı (float), yoksa metin mi (str)? Yanlış tip, yanlış davranış demek: "23.5" + 1 hata verir ama 23.5 + 1 sana 24.5 verir.

Üstelik seri porttan ya da MQTT'den gelen her veri başta metindir — onu doğru tipe çevirmek (cast) IoT'nin en sık yapılan ilk hatasıdır. Bu dersin sonundaki tuzak tam olarak bu.

int
Tam Sayı
Integer · ondalıksız, kesikli

Sayılabilen, bölünmeyen şeyler: kaç adet, kaçıncı pin, hangi ID. Ondalık kısmı yoktur. Negatif olabilir.

17 · GPIO pin no 1023 · ADC ham değer (10-bit) 42 · paket sayacı -67 · RSSI sinyal gücü (dBm) 1718000000 · Unix zaman damgası
python · int
pin = 17                 # LED'in bağlı olduğu GPIO pini
adc_ham = 812            # analog okuma, 0–1023 arası
paket_sayisi = 42       # kaç telemetri paketi geldi

# tam sayılar matematik için hazır:
paket_sayisi = paket_sayisi + 1   # sayacı artır → 43
print(type(pin))     # <class 'int'>
IoT
ADC (analog-dijital çevirici) hep int döner: 10-bit'te 0–1023, 12-bit'te (ESP32) 0–4095. Bu ham sayıyı gerçek birime (volt, °C) çevirince float olur.
float
Ondalıklı Sayı
Floating point · sürekli ölçüm

Gerçek dünyadan gelen ölçümler: sıcaklık, voltaj, GPS koordinatı. Ondalık kısmı vardır. Sensörlerin büyük çoğunluğu float üretir.

23.5 · sıcaklık °C 56.8 · nem % 3.82 · pil voltajı V 1013.25 · basınç hPa 35.6586 · GPS enlem
python · float
sicaklik = 23.5          # DHT22'den gelen °C
pil_voltaj = 3.82        # LiPo hücre voltajı
enlem = 35.6586          # Tokyo — GPS latitude
boylam = 139.7454        # Tokyo — GPS longitude

# ham ADC'yi voltaja çevir → sonuç float:
voltaj = adc_ham / 1023 * 3.3   # 2.62...
print(type(sicaklik))   # <class 'float'>
Hassasiyet
İki uyarı: ① GPS'te ondalık basamak sayısı = hassasiyet. 5 basamak ≈ 1 metre; dronu hassas konumlamak için basamağı kırpma. ② float "yuvarlama hatası" yapar: 0.1 + 0.2 tam 0.3 etmez. Bu yüzden iki float'ı == ile karşılaştırma; eşik/aralık kullan.
str
Metin
String · harf, etiket, mesaj

Üzerinde matematik yapmayacağın her şey: isimler, etiketler, adresler, mesajlar. Tırnak içinde yazılır ("..." veya '...').

"TEMP_01" · sensör ID "DRONE_A7" · cihaz adı "farm/field1/temp" · MQTT topic "OK" · durum mesajı "A4:CF:12:..." · MAC adresi
python · str
sensor_id = "TEMP_01"         # sayı değil, etiket!
topic = "farm/field1/temp"    # MQTT konu yolu
durum = "OK"                  # "OK" / "ERROR" / "CALIBRATING"

# metinler + ile birleşir (matematikle değil):
log = sensor_id + " durumu: " + durum
print(log)            # TEMP_01 durumu: OK
Tuzak
"01" bir metindir, sayı değil. "23.5" da öyle. Seri porttan/MQTT'den gelen veri her zaman metin olarak başlar — birazdan göreceğin en kritik nokta bu.
bool
Mantıksal
Boolean · sadece True / False

İki değerli evet/hayır durumu: True (doğru) veya False (yanlış). Dijital sensörler ve karar mantığının temelidir.

True · PIR hareket algıladı False · kapı kapalı is_armed · drone hazır mı alarm_on · alarm aktif mi
python · bool
hareket_var = True        # PIR sensörü tetiklendi
drone_hazir = False       # henüz arm edilmedi

# bool çoğunlukla bir KARŞILAŞTIRMADAN doğar:
sicaklik = 31.2
cok_sicak = sicaklik > 30.0   # True (bool)

if cok_sicak:                  # karar mantığı
    print("Fanı çalıştır!")
Pro ipucu
Python'da True aslında 1, False ise 0 sayılır. Yani kaç sensörün tetiklendiğini saymak için doğrudan toplayabilirsin: sum([True, False, True]) → 2. IoT'de "kaç düğüm aktif?" sorusuna şık bir cevap.
⚠ IoT'nin 1 numaralı tuzağı: gelen veri metindir

Arduino seri porttan 23.5 "gönderir" ama Python'a ulaştığında o bir str'dir — hatta ham haliyle b'23.5\r\n' gibi bayt dizisidir. Üstünde matematik yapmak istersen önce çevirmen (cast) gerekir, yoksa hata alırsın.

python · cast / çevrim
ham = "23.5"             # seri porttan geldi → str!

# YANLIŞ — metne sayı eklenemez:
# ham + 1   →  TypeError: can only concatenate str

# DOĞRU — önce float'a çevir:
sicaklik = float(ham)    # 23.5  (artık float)
print(sicaklik + 1)      # 24.5  ✓

# tam sayıysa int(), metne dönüş istersen str():
sayac = int("42")        # 42  (int)
mesaj = "Sıcaklık: " + str(sicaklik)  # tekrar metne
Kural
Akılda kalsın: sensörden / ağdan gelen → çevir, sonra hesapla. float() ölçümler için, int() sayaç/ID için, str() ekrana yazdırırken birleştirmek için.

Hepsi bir arada: telemetri paketi

Gerçek bir drone telemetri paketi dört tipi de aynı anda taşır. İşte Tokyo'da uçan bir dronun anlık verisi:

python · telemetri
# --- DRONE TELEMETRİ PAKETİ ---
sensor_id  = "DRONE_A7"      # str   → cihaz etiketi
zaman      = 1718000000     # int   → Unix zaman damgası
enlem      = 35.6586        # float → GPS (Tokyo)
boylam     = 139.7454       # float → GPS (Tokyo)
irtifa_m   = 120            # int   → metre
pil_voltaj = 3.82           # float → volt
arm_durumu = True           # bool  → uçuşa hazır mı

# tipleri tek tek doğrula:
print(type(sensor_id), type(enlem), type(arm_durumu))
# <class 'str'> <class 'float'> <class 'bool'>

# karar mantığı — pil düşükse uyar:
pil_dusuk = pil_voltaj < 3.5    # False (bool)
if arm_durumu and pil_dusuk:
    print(sensor_id + " → ACİL: pil düşük, iniş yap")
Bağ kur
Faz2'de bu paketi MAVLink/pymavlink ile drondan gerçek zamanlı çekeceksin; Faz1'de önce bu tiplerle bir sözlük (dict) kurup MQTT ile yayınlamayı öğreneceksin. Tipleri sağlam oturtmak, o adımı kolaylaştırır.
